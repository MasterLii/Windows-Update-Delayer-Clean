# Windows 更新一键暂停工具 (Windows Update Delayer) - 纯净增强版

这是一款基于 C# 开发的绿色免安装工具，旨在通过修改系统组策略和注册表项，深度控制 Windows 10/11 的自动更新行为。

**本版本为“纯净增强版”：在原版基础上进行了深度重构与视觉优化，移除了所有个人化推广元素，并延长了功能有效期。**

---

## ✨ 核心功能

- **🚀 长期暂停更新**
  - 一键暂停 Windows 更新至 **2027年** (已增强)、2035年或 2054年。
  - 解决系统在工作中强制重启更新的困扰。
- **� 版本锁定 (适用于 Win11)**
  - 指定 Windows 11 保持在特定版本（如 22H2, 23H2 或 24H2）。
  - 防止系统自动升级到下一个不稳定的预览版或大版本。
- **🚫 禁止大版本升级**
  - 有效防止 Windows 10 自动推送并升级到 Windows 11。
  - 锁定当前系统分支，仅允许安全补丁更新。
- **🔄 一键恢复默认**
  - 随时清除所有注册表策略，恢复系统原本的更新检测逻辑。
- **⚡ 快速检查更新**
  - 快捷呼出系统原生“检查更新”设置页面。

## 💎 优化说明 (v2.1 增强版)

1.  **纯净视觉体验**：移除原版所有个人头像、推广链接及弹窗设置，界面更专业、清爽。
2.  **功能期限延长**：将原本的 2026 年暂停节点升级为 **2027 年**，并同步更新后台逻辑。
3.  **UI 交互重构**：
    - 采用现代科技蓝主题配色。
    - 加入交互反馈（按钮悬停半透明、点击缩放效果）。
    - 采用 GroupBox 模块化管理功能区域。
4.  **布局与 Bug 修复**：
    - 修复了原版提示文字遮挡按键的问题，增加了独立的底部状态栏。
    - 修复了原版源码在旧版本 .NET 编译器下无法直接通过编译的 Bug。
5.  **极致绿色**：单执行文件即可运行（建议保留 .config），不常驻后台，不产生系统垃圾。

## 🚀 快速使用

### 📥 软件下载
*   **网盘下载 (绿色打包版)**：[夸克网盘 (提取码：无)](https://pan.quark.cn/s/d9e177d518d1)
*   **本地发布**：也可以在本项目 [Releases](https://github.com/) 页面下载编译好的二进制文件。

### 运行环境
- **操作系统**：Windows 10 / Windows 11 (支持所有分支)
- **必备组件**：.NET Framework 4.8 或更高版本 (Win10/11 系统通常已自带)

### 运行步骤
1. 下载打包好的 `Windows一键暂停更新.exe`。
2. **右键点击程序 -> 选择“以管理员身份运行”**（必须，否则无法修改注册表）。
3. 根据需要点击功能按钮即可。修改成功后，建议重启系统使策略立即完全生效。
